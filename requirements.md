 Library App Requirements

 1. Project Scope

The Library App is a simple web application that allows students to view books, search by title or author, check availability, borrow books, and return books.

 2. Functional Requirements

- FR1: The system shall display a list of books.
- FR2: Users shall be able to search books by title or author.
- FR3: The system shall show whether each book is available or borrowed.
- FR4: Users shall be able to borrow available books.
- FR5: Users shall be able to return borrowed books.
- FR6: The system shall display a message when no matching books are found.

 3. Non-Functional Requirements

- NFR1: The interface shall be simple and easy to use.
- NFR2: Search results should appear within 2 seconds under normal conditions.
- NFR3: Status and error messages shall be clear.
- NFR4: The application should work in modern desktop and mobile browsers.

 4. User Stories

1. As a student, I want to view the book list so that I can choose a book.
2. As a student, I want to search by title or author so that I can find books quickly.
3. As a student, I want to check availability before borrowing a book.
4. As a student, I want to borrow an available book.
5. As a student, I want to return a borrowed book.
6. As a librarian, I want to manage book records. This is a future enhancement.

 5. Constraints

- The prototype uses sample book data.
- Book status changes are not saved permanently.
- Login and database functionality are not included.

 6. Success Criteria

- The book catalogue is displayed correctly.
- Searching by title and author works.
- Book availability is displayed correctly.
- Borrow and Return actions update the displayed status.
- A message appears when no matching books are found.
