Library App – Team Retrospective

1. What Went Well?

* The project requirements and scope were defined.
* The website was developed using HTML, CSS, and JavaScript.
* Multiple pages were created for library operations.
* GitHub Pages was used to publish the prototype.

2. Challenges Faced

* Organising multiple website files.
* Connecting the HTML pages with CSS and JavaScript.
* Testing the navigation and book operations.
* Preparing project documentation.

3. What Can Be Improved?

* Perform more comprehensive testing.
* Improve accessibility and mobile responsiveness.
* Add secure authentication.
* Store book information in a database.

4. Lessons Learned

The project provided practical experience in web development, requirements analysis, Agile development, testing, and GitHub-based collaboration.

5. Future Enhancements

* Secure student login.
* Librarian dashboard.
* Database integration.
* Book issue dates and due dates.
* Borrowing history and notifications.

Conclusion

The project demonstrates the basic features of a Library Management App. Further improvements can make it suitable for real-world library operations.
