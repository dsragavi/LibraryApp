Library App – Workflow and SDLC

Selected SDLC Model

Agile Software Development Life Cycle (SDLC)

Reason for Choosing Agile

Agile supports incremental development, continuous testing, team collaboration, feedback, and regular improvement.

Development Workflow

1. Planning – Define project goals and scope.
2. Requirements Analysis – Identify functional and non-functional requirements.
3. Design – Prepare the wireframe and workflow diagram.
4. Development – Build the website using HTML, CSS, and JavaScript.
5. Testing – Execute test cases and identify defects.
6. Review – Review the prototype and collect feedback.
7. Improvement – Fix defects and improve the application.

User Workflow

Start → Open Library App → View Home Page → Search for a Book → Check Availability

If Available → Borrow Book → Display Updated Status

If Borrowed → Return Book → Update Availability

If No Match → Display No Books Found

Future Iterations

Future versions may include secure authentication, database integration, librarian management, and borrowing history.
